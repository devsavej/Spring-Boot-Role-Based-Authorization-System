# Spring Boot Role-Based Authorization 🔐

A Spring Boot project demonstrating **Spring Security authentication and role-based authorization** for securing REST APIs.

## 🚀 Features

* User Authentication
* Role-Based Authorization
* `ROLE_USER` and `ROLE_ADMIN`
* BCrypt Password Encryption
* Secure REST APIs
* Exception Handling
* MySQL Database Integration

## 🛠️ Tech Stack

* Java
* Spring Boot
* Spring Security
* Spring Data JPA
* Hibernate
* MySQL
* Maven
* Postman

## 🎯 Purpose

Built to understand and implement **Spring Security, Authentication, Authorization, Roles, Authorities, and API Security** in a Spring Boot application.
